# 🏠 House Price Prediction Using Deep Feedforward Neural Network (FFNN)

## 📌 Project Overview

This project uses a Deep Feedforward Neural Network (FFNN) to predict house prices based on various housing features.

The model learns the relationship between house characteristics such as area, number of bedrooms, bathrooms, parking facilities, and other attributes to estimate the selling price of a house.

## 🎯 Objectives

- Perform data preprocessing and cleaning.
- Analyze the dataset using Exploratory Data Analysis (EDA).
- Split the dataset into training and testing sets.
- Build a Deep Feedforward Neural Network.
- Train the model using housing data.
- Evaluate the model using regression metrics.
- Predict house prices based on input features.

## 📊 Dataset

- **Dataset:** Housing Price Prediction Dataset
- **Number of Records:** 545
- **Target Variable:** Price
- **Problem Type:** Supervised Learning — Regression

The dataset contains numerical and categorical features related to residential properties.

## 🧠 Model Architecture

The project uses a Deep Feedforward Neural Network (FFNN), also known as a Multilayer Perceptron (MLP).

The model learns patterns from the input housing features and predicts a continuous numerical value representing the house price.

## ⚙️ Project Workflow

4. Encode categorical variables.

8. Train the model.
9. Generate predictions.
10. Evaluate model performance.

## 📈 Evaluation Metrics

The model can be evaluated using regression metrics such as:

- **MAE:** Mean Absolute Error
- **MSE:** Mean Squared Error
- **RMSE:** Root Mean Squared Error
- **R² Score:** Coefficient of Determination

These metrics help measure the difference between actual and predicted house prices.
